# Three Truths and a Lie

A fully scripted party game for Reachy Mini, built for Science Night Glasgow (October 2026). Reachy plays 8 pre-recorded, human-approved clips, one per button press from a phone remote. No LLM, no live speech generation, no microphones, no internet at runtime.

Code, tests and the full write-up: https://github.com/anarojoecheburua/reachy-three-truths
